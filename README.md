# sayvo-status

يراقب سيرفر سايفو (`api.nrg-egypt.com`) كل ربع ساعة من GitHub.
لو السيرفر ما ردّش 3 مرات ورا بعض، بيتفتح إيشو «⚠️ السيرفر مش بيرد» وGitHub بيبعت إيميل. ولما يرجع يرد، الإيشو بيتقفل لوحده.

الريبو عام عشان دقايق GitHub Actions تبقى ببلاش. مفيهوش أي سر: عناوين عامة والمفتاح العام اللي موجود أصلاً في التطبيق.
تشغيل يدوي: Actions → server-watch → Run workflow.
